# Search and move around

| Key | Action |
| --- | --- |
| `Ctrl+F` / `Cmd+F` | Find in PDF |
| `Enter`, `Shift+Enter` | Next or previous match |
| `←` `→` | Previous or next page |
| `Ctrl+=`, `Ctrl+-` | Zoom in, zoom out |

The sidebar button on the left of the toolbar opens the outline and the page thumbnails.
